# AUREC.SAS | Framework Académico y Metodologías de Grado con IA

Repositorio de acceso abierto con directrices, matrices de evaluación de jurados y protocolos de dirección de trabajos de investigación contable, financiera y de control interno.

**Firma:** aurec.sas — Asesoría y Consultoría Contable y Tributaria  
**Autor:** C. P. Edgar J. Martínez A.  
**Propósito:** Proporcionar un marco metodológico estructurado para estudiantes y docentes universitarios que integran Inteligencia Artificial en la investigación formativa.

---

## Estructura del Repositorio

- `Skills_Academicas/01_Direccion_Trabajos_Grado/`: Protocolos de tutoría pedagógica, alineación vertical (Título ↔ Problema ↔ Objetivos) y matrices de consistencia metodológica.
- `Skills_Academicas/02_Evaluacion_Trabajos_Grado/`: Baremos de dictamen para jurados evaluadores, rúbricas cuantitativas y emisión de conceptos técnicos.
