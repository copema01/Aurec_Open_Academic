Bloque 01 — Fundamentos e IDLE

Un programa es una secuencia de instrucciones escritas con reglas precisas

Un lenguaje de programación es un lenguaje formal con reglas bien definidas que nos permite comunicarnos con la computadora. A diferencia del habla cotidiana, cada instrucción debe seguir su sintaxis exacta; esa serie de pasos guardada en un archivo conforma un programa.

Python destaca por su sintaxis clara, cercana al inglés cotidiano y altamente pedagógica. Para empezar, se descarga desde la web oficial python.org en la sección Downloads (teniendo en cuenta que Python 3.9 en adelante no es compatible con Windows 7 o versiones anteriores). Durante el asistente, se recomienda la instalación por defecto para todos los usuarios; marcar la casilla de línea de comandos es opcional.

Las dos caras de IDLE

Al instalar Python se incluye IDLE, un entorno integrado de programación que reúne tres capacidades esenciales: escribir archivos, editarlos y ejecutar código.

Shell interactivo

Identificado por las tres flechas >>>. Evalúa una instrucción al instante tras pulsar Enter (por ejemplo 5 + 5 devuelve 10 en azul).

Archivo .py

Creado con File → New File. Permite escribir programas completos, mostrar números de línea desde Options → Configure IDLE y ejecutarlos con Run → Run Module.

Tu primer programa — hola_mundo.py
print("¡Hola, Mundo!") # Salida en el shell interactivo: ¡Hola, Mundo!

print() es una función incorporada que muestra en pantalla el mensaje encerrado entre comillas. Guardar el archivo con extensión .py indica que contiene código Python reutilizable.

Bloque 02 — Variables y Tipos Básicos

Las variables reservan memoria con nombre y distinguen mayúsculas

Una variable es un nombre asignado a un espacio en la memoria de la computadora donde alojamos un valor. Se crea con el operador de asignación = (se recomienda dejar un espacio a cada lado por claridad): num = 15. Si luego escribimos num = 8, actualizamos el valor guardado en ese espacio; si evaluamos num + 2, Python reemplaza num por 8 y devuelve 10.

Python distingue entre mayúsculas y minúsculas (case-sensitive): edad = 24, Edad = 70 y EDAD = 15 son tres variables independientes en memoria.

Tipo de dato Clase en type() Ejemplos del curso Nota clave
Entero <class 'int'> 5, -15, 0 Sin decimales; tamaño solo limitado por la memoria del equipo.
Coma flotante <class 'float'> 0.5, 13.4, 4.0, 0.0 Todo número con punto decimal, incluso si termina en .0.
Booleano <class 'bool'> True, False Palabras reservadas que siempre inician con mayúscula.
Cadena (String) <class 'str'> "Nora", "5", "" Texto entre comillas; "5" no permite aritmética como el entero 5.

Bloque 03 — Cadenas de Caracteres e Input

Indexar accede a un carácter; rebanar recorta sin lanzar errores de rango

Las cadenas (str) son secuencias de caracteres encerradas entre comillas simples o dobles (siempre consistentes: mezclarlas causa SyntaxError: EOL while scanning string literal). La función len() devuelve su longitud: len("") es 0, len("Nora") es 4 y len("Python") es 6.

Cada carácter ocupa una posición numerada desde 0 (numeración basada en cero). Con corchetes palabra[i] accedemos a un carácter; si el índice supera la longitud, Python detiene la ejecución con IndexError: string index out of range. En cambio, el rebanado (slicing) usa cadena[inicio:fin:paso], donde fin no se incluye y los índices fuera de rango se ajustan sin error.

Interacción con el usuario

input() siempre devuelve texto

Aunque el usuario escriba 5 o True, input("Ingrese un número: ") entrega una cadena str. Para operar aritméticamente debemos envolverla: num = int(input("Ingrese un número: ")).

Bloque 04 — Operadores y Condicionales

Expresiones, precedencia PEMDAS y decisiones con if / elif / else

1. Aritméticos

Cálculo y concatenación

+ suma números o concatena cadenas. / siempre devuelve float (15 / 5 → 3.0); dividir entre 0 causa ZeroDivisionError. // realiza división entera truncando decimales (3 // 5 → 0). ** eleva a potencia (5 ** 3 → 125) y % da el resto (5 % 2 → 1 para detectar impares). Orden: PEMDAS (Paréntesis, Exponentes, Multiplicación/División, Adición/Sustracción).

2. Lógicos y Relacionales

Comparar y combinar verdad

Relacionales (>, >=, <, <=, ==, !=) evalúan a booleano; en cadenas comparan orden lexicográfico ("a" < "b" es True). Lógicos: prioridad not > and > or.

3. Asignación compuesta

Operar y guardar

Combinan un operador aritmético con =: edad += 3, edad -= 2, edad *= 3, edad /= 2, num %= 2. Si num = 6 y aplicamos num %= 2, su valor final es 0.

Bloque 06 — Documentación y Ciclos

Repetir instrucciones con control: for sobre secuencias y while por condición

Antes de escribir ciclos complejos, conviene saber leer la documentación oficial en python.org (disponible en español desde su selector de idioma). En la Referencia de la Biblioteca → Funciones integradas encontrarás firmas como round(number[, ndigits]) —donde los corchetes marcan parámetros opcionales— o sorted(iterable, *, key=None, reverse=False) —donde = indica valores por defecto—.

Los ciclos (o bucles) son estructuras de control que ejecutan repetidamente un bloque indentado. Usamos for cuando sabemos de antemano cuántas iteraciones haremos —ya sea con range(start, stop, step) o recorriendo un iterable (cadenas, listas, tuplas o diccionarios con .values() y for clave, valor in d.items():)—. Usamos while cuando la repetición depende de que una condición siga siendo verdadera, actualizando manualmente la variable para evitar un ciclo infinito (que en IDLE se detiene con Ctrl + C o Shell → Interrupt Execution).

Comparativa for vs. while
# for con range(stop) for i in range(4): print(i) # 0, 1, 2, 3 # while con actualización explícita x = 20 while x < 35: print(x) x += 3 # evita ciclo infinito

Bloque 07 — Funciones, Scope y Recursión

Reutilizar lógica con DRY y resolver problemas llamándose a sí mismo

Funciones, parámetros, return y scope

Siguiendo el principio DRY (Don't Repeat Yourself), agrupamos tareas en bloques con def nombre_funcion(parametros):. Los parámetros van en la definición; los argumentos son los valores concretos enviados al llamar a la función.

La sentencia return devuelve un resultado al punto de llamada y detiene de inmediato la función (si falta return, Python devuelve None por defecto). Además, cada función crea su propio scope local: las variables definidas en el programa principal son globales, mientras que los parámetros y variables locales solo existen dentro de la función.

Anatomía de una función recursiva

La recursión define una función en términos de sí misma, como la sucesión de Fibonacci donde cada término suma los dos anteriores. Toda función recursiva exige dos partes:

  • Caso base: detiene las llamadas (if n == 0 or n == 1: return n).
  • Caso recursivo: reduce el problema hacia el caso base (fibonacci(n - 1) + fibonacci(n - 2)).

Bloque 08 — Archivos, Módulos, Excepciones y POO

De scripts robustos a objetos: archivos, try/except y clases

Archivos de texto

Sentencia with open(...)

Cierra el archivo automáticamente al salir del bloque indentado. Modos principales: "r" (leer, por defecto), "w" (escribir reemplazando todo el contenido), "a" (añadir al final con .write(... + "\n")), más + (como "w+") para sumar lectura.

Módulos e importaciones

Organizar proyectos crecientes

Un módulo es un archivo .py con funciones y constantes relacionadas. Formas recomendadas: import math (math.pow(9, 2), math.pi), alias import math as matematicas o puntual from math import pow. Se desaconseja from math import * porque oculta de dónde proviene cada nombre.

Manejo de excepciones

Simulador try / except / else / finally

Mientras los errores de sintaxis (SyntaxError, IndentationError) impiden arrancar el programa, las excepciones (IndexError, KeyError, NameError, ZeroDivisionError) ocurren en ejecución y pueden capturarse.
